# plugin-test

Marketplace bac à sable `theodo-lab`, pour prototyper la mécanique de packaging et de
distribution des plugins Claude (chat, Claude Desktop, Cowork). Plugin disponible :
**menu-digest** — résume la carte d'un restaurant fournie en PDF selon un format fixe
en 5 sections.

## Installation

- claude.ai : `Customize > Plugins > Add marketplace`, coller
  `https://github.com/theodore2leusse/plugin-test`, installer `Menu Digest`.
- Claude Code : `/plugin marketplace add theodore2leusse/plugin-test` puis
  `/plugin install menu-digest@theodo-lab`.

> ⚠️ Contenu de démonstration, sans garantie ni usage en production.
